# LingoGrab｜上线、域名、备案与 SEO 方案

更新时间：2026-10-13

## 当前线上结构

- 前端：EdgeOne Makers，正式生产地址 `https://lingograb.com/`
- 代码：GitHub `https://github.com/jialecai0308/lingograb`，`main` 分支自动部署到生产环境
- AI：EdgeOne Function `https://www.getyuli.com/api/pickup`
- 账号 / 同步 / 反馈：EdgeOne Functions + Supabase；前端只持有用户 token，数据库密钥不下发
- 本地优先：未登录也能学习；登录后把 `pickup_state_v1` 同步到云端
- 旧地址：`https://lingograb.getyuli.com/`，由边缘中间件以 301 保留路径和查询参数后跳转到正式域名

## 域名建议

### 正式域名

主域名统一使用 `lingograb.com`；页面 canonical、Open Graph、Schema.org、robots 与 sitemap 均只声明该地址。`www.lingograb.com` 在 EdgeOne 关联、验证并签发证书后，也永久跳转到不带 `www` 的主域名。

### 旧地址迁移

旧子域名继续接入同一个 EdgeOne Makers 项目，但不再作为可索引页面：边缘中间件对旧主机返回 301，目标固定为 `https://lingograb.com`，同时保留原路径和查询参数，避免形成多跳链路。

## 推荐路径

1. 在 EdgeOne Makers 项目中保持 `lingograb.com` 为生产主域名。
2. 添加并验证 `www.lingograb.com`，按控制台给出的记录完成 DNS 与证书签发；不要手工猜测 CNAME 目标。
3. 发布包含 301 中间件以及新域 canonical、Open Graph、Schema.org、`robots.txt`、`sitemap.xml` 的版本。
4. 分别验收主域 200、旧域和 `www` 单跳 301，并确认深层路径与查询参数不会丢失。
5. 在 Google Search Console 与 Bing Webmaster Tools 添加新域、提交 sitemap，并持续观察抓取和索引迁移。

## ICP 备案提醒

- 个人非经营性网站可凭本人身份证备案，不要求个体工商户营业执照。
- 如果要公开收费、销售会员或长期作为商业产品运营，更建议以个体工商户或公司作为备案主体；个体工商户营业执照可作为单位备案材料。
- 域名实名认证主体应与备案主体一致；还需要中国大陆备案资源、负责人手机号/邮箱、视频核验，并按所在地管局要求补充居住证明等材料。
- 获得 ICP 备案号并正式开站后，通常还应在 30 日内办理公安联网备案。
- 当前 `getyuli.com` 使用 EdgeOne Pages。未备案时只能使用“全球可用区（不含中国大陆）”；要切换中国大陆或全球含大陆节点，需要先完成 ICP 备案。
