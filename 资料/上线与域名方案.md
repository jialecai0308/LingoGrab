## 域名建议

### 作品集过渡地址

在独立域名确定前继续保留 GitHub Pages 公网地址。若临时需要品牌化子域名，可使用 `lingograb.getyuli.com`；它适合演示，不建议作为长期主域名。

### 独立域名候选

品牌已确定为 `LingoGrab`。正式购域名前需再次核查 `.com`、`.app`、`.cn` 的实时注册状态、同类商标和社媒账号；不要继续购买包含 `pickup` 或 `shide` 的旧品牌域名。

RDAP 404 只能说明查询当时未发现注册记录，不等于锁定；最终以注册商结算页为准。

## 推荐路径

1. 先完成 LingoGrab 品牌替换并继续用 GitHub Pages 验证。
2. 在 EdgeOne Pages 新建独立的 `lingograb` 项目，与愈历的 Functions 和额度逐步解耦。
3. 购买正式域名后绑定 EdgeOne；域名若启用中国大陆节点，先完成 ICP 备案。
4. 域名生效后，把 canonical、Open Graph URL、`robots.txt` 和 `sitemap.xml` 一次性替换为正式地址。

## ICP 备案提醒

- 个人非经营性网站可凭本人身份证备案，不要求个体工商户营业执照。
- 如果要公开收费、销售会员或长期作为商业产品运营，更建议以个体工商户或公司作为备案主体；个体工商户营业执照可作为单位备案材料。
- 域名实名认证主体应与备案主体一致；还需要中国大陆备案资源、负责人手机号/邮箱、视频核验，并按所在地管局要求补充居住证明等材料。
- 获得 ICP 备案号并正式开站后，通常还应在 30 日内办理公安联网备案。
- 当前 `getyuli.com` 使用 EdgeOne Pages。未备案时只能使用“全球可用区（不含中国大陆）”；要切换中国大陆或全球含大陆节点，需要先完成 ICP 备案。
