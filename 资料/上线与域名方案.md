# 拾得 Pickup｜上线、域名与 SEO 方案

更新时间：2026-09-26

## 当前线上结构

- 前端：GitHub Pages，公开地址 `https://jialecai0308.github.io/shide-pickup/`
- AI：EdgeOne Function `https://www.getyuli.com/api/pickup`
- 账号 / 同步 / 反馈：EdgeOne Functions + Supabase；前端只持有用户 token，数据库密钥不下发
- 本地优先：未登录也能学习；登录后把 `pickup_state_v1` 同步到云端

## 域名建议

### 可立即使用

`pickup.getyuli.com`

优点：不需要购买新域名、今天即可配置、能体现这是同一位创作者的产品矩阵。缺点：品牌独立性略弱。

### 独立域名候选

2026-09-26 通过 Verisign RDAP 查询时：

- `pickuplang.com`：未查询到注册记录，推荐度最高；含义清楚、便于海外展示
- `shidepickup.com`：未查询到注册记录；保留中文品牌拼音
- `pickupfrench.com`：未查询到注册记录；过度绑定法语，不建议作为长期主域名

RDAP 404 只能说明查询当时未发现注册记录，不等于锁定；最终以注册商结算页为准。

## 推荐路径

1. 作品集阶段先使用 `pickup.getyuli.com`，将 DNS 的 CNAME 指向 `jialecai0308.github.io`。
2. 在 GitHub Pages 仓库配置 Custom domain，并开启 HTTPS。
3. 域名生效后，把 `index.html` 的 canonical / Open Graph URL、`robots.txt` 和 `sitemap.xml` 一次性替换为正式域名。
4. 产品验证后再购买 `pickuplang.com`，避免过早为未验证品牌承担迁移成本。

## 已具备的 SEO 基础
