# LingoGrab：AI 与代码分层方案

## 结论

MVP 最经济、可靠的方案不是“所有内容都实时问 AI”，也不是先手工建设一套巨大知识库，而是四层混合架构：

1. **本地确定性代码**负责对错、重输、复习进度与状态同步。
2. **词书缓存内容**负责例句、答案、核心用法和语法事实。
3. **构建期 AI**批量生成候选学习卡，经自动校验和抽检后写入缓存。
4. **实时 AI**只用于个人材料筛选和用户主动触发的“换个讲法”。

这样能把高频学习路径的边际模型成本降到接近零，同时保留 AI 在开放语义任务上的价值。

## 四层职责

| 层级 | 负责内容 | 何时运行 | 是否调用模型 | 失败策略 |
|---|---|---|---|---|
| L0 本地代码 | 答案标准化、对错判断、答错重输、学习进度、复习调度 | 每次学习 | 否 | 本地功能持续可用 |
| L1 词书缓存 | 题目、标准答案、例句、核心用法、法语变位与时态标签 | 每次学习直接读取 | 否 | 读取上一已发布版本 |
| L2 构建期 AI | 从词频与主题种子生成候选卡、释义、例句和解释 | 内容生产或版本更新时批量运行 | 是，但不是用户每次答题时 | 失败任务重试，不影响线上版本 |
| L3 实时 AI | 个人导入筛选、按当前错题换个讲法 | 用户主动点击时 | 是 | 降级到本地规则或保留核心用法 |

## 当前 MVP 已实现到哪里

### 已实现

- L0：答案判定、答错必须重输、进度与学习记忆均由前端代码处理。
- L1：现有样板学习卡及核心用法已经随站点缓存，学习时不会请求模型。
- L3：个人导入智能筛选与“AI 换个讲法”通过服务端代理实时请求模型。
- 降级路由：`glm-4.7-flash` → `glm-4-flash-250414` → 本地规则。
- 前端标识：学习反馈区会区分“词书缓存”和“实时 AI”；设置页解释每层职责。

### 尚未完成

- L2 的自动化批量生产脚本、内容版本库和审核后台尚未落地。
- 当前样板卡是已校验的静态内容，不能把全部 5,000 词描述成“已经生成 5,000 张学习卡”。
- 正式间隔重复算法、批量质量评分和人工审核工作台仍属于下一阶段。

## 构建期 AI 的推荐实现

输入不是整本词表一次塞给模型，而是按 20–50 个词分批：

```text
开源词频 / 主题种子
  → 去重、词性和噪声过滤
  → AI 批量生成候选卡
  → JSON Schema 校验
  → 规则校验与重复检测
  → 低置信度进入人工抽检
  → 发布为带版本号的只读词书 JSON
```

每张卡至少保存：

- `id`：稳定标识；
- `language`、`level`、`topic`：语言、难度与场景；
- `target`、`lemma`：答案与词元；
- `cloze`、`translation`：练习句和中文提示；
- `coreUsage`、`grammarTags`：核心用法与语法标签；
- `source`：词频、公开语料或编辑来源；
- `generationModel`、`promptVersion`：生成模型与提示词版本；
- `reviewStatus`、`reviewedAt`：自动校验或人工抽检状态；
- `contentVersion`：用于回滚的内容版本。

生成结果先写入 `draft`，只有通过规则校验并达到抽检要求的内容才能进入 `published`。线上学习只读取 `published`，不直接读取模型刚生成的内容。

## 最经济的调用策略

### 必须实时调用

- 用户粘贴一段此前未知的材料，请系统判断哪些表达值得学；
- 用户不理解已有解释，主动请求结合当前错误换一种说法。

### 不应实时调用

- 每次判断答案；
- 每次展示同一张词卡；
- 查询法语固定变位和时态事实；
- 计算下次复习时间；
- 加载已发布的系统词书。

### 可以批量调用

- 新词书初次生产；
- 例句或核心用法的版本升级；
- 针对岗位或主题批量扩充候选内容。

## 缓存和成本控制

1. 系统词书以版本化 JSON 或数据库记录发布，并由 CDN 缓存。
2. “换个讲法”可用 `cardId + 错误类型 + 语言 + promptVersion` 做短期缓存，重复问题复用结果。
3. 个人导入只传用户主动提交的当前片段，限制长度与每次返回数量。
4. 服务端限制每分钟和每日请求量，只允许免费模型白名单。
5. 模型失败时绝不自动切换到付费模型。

## 质量分层

- **A级：人工确认**——法语变位、时态、标准答案及高频核心卡。
- **B级：规则校验 + 抽检**——普通例句、释义、搭配说明，可进入正式词书。
- **C级：AI 即时生成**——换个讲法，只作辅助说明，必须明确标记为实时 AI。

这套分层的关键不是让用户理解技术名词，而是让用户知道：什么是稳定课程内容，什么是现场生成的辅助解释，以及 AI 暂时不可用时哪些功能仍然能用。
