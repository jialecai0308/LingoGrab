# 拾得 Pickup

> 把读过的东西，变成记得住的东西。

**在线 Demo** 👉 https://jialecai0308.github.io/shide-pickup/

这是一个面向职场人的英法语言学习 MVP（数据为演示用）。它把「结构化课程 → 情境填空 → 错题解析 → 个人拾取 → 间隔复习」做成一条可以持续体验的闭环。

---

## 一句话

**把工作和阅读中遇见的英语、法语，变成今天能学、以后能用的个人语言课。**

## 当前 Demo 已包含

- 今日学习面板与英法双词库切换；
- Lingvist 式情境填空、答案判断与错题解析；
- 法语动词 / 时态速查；
- 文本导入后的高价值表达识别与一键入库；
- 本地进度、掌握词和个人词库持久化；
- 移动端适配。

## 三轮驱动

1. **结构化词库**：没有素材也能直接学，保证课程骨架与难度梯度。
2. **AI 推荐 / 精选**：根据岗位、水平、错题和已掌握词，控制“刚好够难”。
3. **个人导入**：文章、会议纪要与工作表达进入个人语言资产。

## 学习闭环

1. 选词库或导入真实材料。
2. 系统筛出值得学习的词与搭配。
3. 在情境句中主动回忆，不孤立背词义。
4. 答错后解释“为什么”，英语讲搭配，法语讲变位和时态。
5. 把掌握度写回个人模型，决定下一次出现时间。

## Origin Story（怎么想出来的）

我在一家跨境电商公司做出海产品经理，一直在提升英语。我先给自己搭了一个「双语库」——不是背单词，而是让 AI **自动从我每天真实接触的英文内容里**，把值得记的词和表达「拾」出来，配上原句情境和出处，重点标黄，定期复习，越用越懂我。

用了一阵我意识到：**「从你真实接触的内容里，自动拾取值得记住的东西 + 带情境溯源 + 间隔复习」这套机制，不该只属于英语、只属于我——每个爱学习的人都需要。** 于是把「自动采集」换成「用户主动投喂」，把「英语」扩展成「任何值得记住的内容」，就有了**拾得 Pickup**。
